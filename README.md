# محاسبه‌گر مساحت و محیط مستطیل

این پروژه یک برنامه ساده پایتون است که طول و عرض مستطیل را از کاربر دریافت کرده و مساحت و محیط آن را محاسبه می‌کند.

## قابلیت‌ها

- دریافت طول مستطیل از کاربر
- دریافت عرض مستطیل از کاربر
- محاسبه مساحت مستطیل
- محاسبه محیط مستطیل
- نمایش نتایج در ترمینال

## نحوه اجرا

ابتدا مطمئن شوید پایتون روی سیستم شما نصب است.

سپس فایل پروژه را اجرا کنید:

```bash
python main.py
```

## نمونه اجرا

```text
طول مستطیل را وارد کنید: 10
عرض مستطیل را وارد کنید: 5

مساحت مستطیل: 50
محیط مستطیل: 30
```

## فرمول‌ها

مساحت:

```text
طول × عرض
```

محیط:

```text
2 × (طول + عرض)
```
